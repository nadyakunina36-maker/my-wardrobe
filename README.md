# Мой гардероб
Персональное PWA-приложение для хранения вещей и подбора образов.

## Первая версия
- каталог гардероба по категориям;
- готовые рабочие образы;
- подбор образа из вещей владельца;
- отметки «Нравится» и «Надела»;
- признак сумки для MacBook.

Следующий этап: реальные фотографии вещей, постоянное локальное хранение карточек и добавление вещи по фото.
